# FL Baselines Docs

Tài liệu được tách theo chủ đề để dễ đọc và dễ bảo trì.

## Mục Lục

1. [README](README.md): guide tổng quan cho folder `docs/` và mô tả từng file.
2. [Overview](overview.md): mô tả project, mục tiêu thiết kế và baseline hiện tại.
3. [Quickstart](quickstart.md): cài đặt, chạy experiment và override config.
4. [Architecture](architecture.md): kiến trúc code, luồng chạy server/client, registry và config.
5. [Datasets](datasets.md): các dataset builder và partitioner.
6. [Models](models.md): các model builder và vision backbone.
7. [Algorithms](algorithms/index.md): mục lục algorithm; mỗi algorithm có một file riêng.
8. [Extending Baselines](extending-baselines.md): cách mở rộng dataset/model/algorithm và thêm baseline hoàn chỉnh.
9. [Testing And Artifacts](testing-and-artifacts.md): test suite, gợi ý test khi thêm component, và output artifacts.
