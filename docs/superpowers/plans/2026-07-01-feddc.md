# FedDC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a paper-aligned `feddc` baseline with client drift decoupling, gradient correction, persisted per-client state, and a repo-consistent server strategy.

**Architecture:** Implement `FedDCStrategy` as a `FedAvg`-style strategy with a persisted server-side average update state `g`. Implement client-side FedDC optimization in a dedicated training helper, persist `h_i` and `g_i` per client under `output-dir`, and route `TorchFlowerClient` through an algorithm-gated `feddc` fit path.

**Tech Stack:** Python, PyTorch, Flower, unittest
