# FedProto Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a classifier-compatible `fedproto` baseline with prototype aggregation on the server, prototype regularization on clients, and model-agnostic feature extraction helpers for the current model set.

**Architecture:** Implement `FedProtoStrategy` as a `FedAvg`-style strategy that sends global prototypes alongside model parameters and aggregates returned local prototypes by class. Implement dedicated feature-extraction and local-training helpers so FedProto can regularize penultimate embeddings without changing the public `forward()` contract of existing models.

**Tech Stack:** Python, PyTorch, Flower, unittest
