# FedExP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `fedexp` baseline that keeps the current FL pipeline intact while replacing FedAvg server aggregation with the adaptive extrapolation step from the FedExP paper.

**Architecture:** Implement FedExP as a new server strategy builder alongside the existing algorithms. Reuse the default client training path so local optimization remains identical to FedAvg, and apply the FedExP adaptive server step only in `aggregate_fit`, with a new non-negative `fedexp-epsilon` config knob for denominator stabilization.

**Tech Stack:** Python, Flower strategies, NumPy, PyTorch, unittest
