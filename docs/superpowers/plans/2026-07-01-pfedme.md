# pFedMe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a paper-aligned `pfedme` baseline with custom server mixing, client-side proximal personalization, persisted personalized state, and repo-consistent config/docs/tests.

**Architecture:** Implement `PFedMeStrategy` as a `FedAvg`-style strategy with custom `aggregate_fit(...)` that mixes the previous global model with the averaged client reference models using `beta`. Implement client-side personalized training in a dedicated `training/pfedme.py` helper and route `TorchFlowerClient` through an algorithm-gated `pfedme` fit path.

**Tech Stack:** Python, PyTorch, Flower, unittest
