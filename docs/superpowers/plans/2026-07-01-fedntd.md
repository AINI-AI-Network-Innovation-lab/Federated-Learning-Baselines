# FedNTD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a paper-aligned `fedntd` baseline that changes only the client-side training loss while preserving the current server aggregation and evaluation pipeline.

**Architecture:** Implement `FedNTDBuilder` as a thin `FedAvg`-style builder with FedNTD-specific fit config. Implement a dedicated `training/fedntd.py` helper for not-true distillation against the broadcast global model, then route `TorchFlowerClient` through an algorithm-gated FedNTD fit path.

**Tech Stack:** Python, PyTorch, Flower, unittest
